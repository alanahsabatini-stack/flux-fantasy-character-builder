# Flux Fantasy Character Builder

A web-based character creation and management tool for Flux Fantasy.

## Current Status

The Character Creator is currently being updated to support Version 1.1 of the Flux Fantasy Character Creation Guide.

Completed:
- Character creation form and basic validation
- Karma Specialty and Study selection
- Karma Power tables
- Advanced Karma Power Effect selection
- Advanced Effect validation during character finalization
- Character Summary
- Basic styling and responsive table layout

In Progress:
- V1.1 Powers updates
- Non-Karma Attack updates
- Power Theme
- Skill Tree and Level Up functionality

Planned:
- Final testing and refinement
- Additional V1.1 mechanics
